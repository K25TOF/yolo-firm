**Analyst:** Analyst here —

I've identified three failure modes where HYP-025's entry fires but the trade fails. Ordering by likelihood and impact:

## 1. **VWAP distance signal is corrupted on sub-$1 stocks (HIGHEST RISK)**

**The problem:**
- VWAP on $0.40 stocks (MOBX, DXST) is dominated by bid-ask spread noise, not trend conviction
- Bid-ask spread on sub-$1 momentum names is 1–5% of price
- A single block trade can move VWAP 0.5–2%
- Result: "price >= VWAP × 1.02" fires on noise, not uptrend confirmation
- We're betting the entire grind profile on VWAP validity, but VWAP is unreliable at these price levels

**Evidence:**
- HYP-024 showed VWAP >= 10% distance filter improved WR by +4.2pp but failed validation (+5pp bar)
- Sub-$1 VWAP volatility was flagged (EXP-017 notes) but never quantified
- 39 of 49 tickers in EXP-023 include sub-$1 names — if VWAP is corrupt on them, we're testing on bad data

**Why this is the biggest risk:**
- Entry signal is 3-way AND gate: lose VWAP validation and the entire filter collapses
- We cannot validate this with backtesting alone — the backtest uses the same VWAP data
- In live trading, a VWAP-based rule on sub-$1 stocks would likely produce false entries on bid-ask bounces, not real trend moves

---

## 2. **EMA gap acceleration threshold (< 1.0%) doesn't scale across profiles**

**The problem:**
- EXP-021 found accelerating gap = -54.9% PnL, but that analysis mixed impulse (vol_filter, 3%+ gap) and grind (lower gap) trades
- A 0.1% acceleration in a 1.0% gap is proportionally larger noise than 0.1% in a 3.0% gap
- Threshold of 1.0% may be too loose for the grind regime where we're already entering on modest gap changes
- Different volatility profiles (MDBX vs CCHH) might require different acceleration tolerances

**Why it matters:**
- Skip-first filter removed 34 trades but saved -83pp PnL — it worked because first entries are genuinely bad
- Acceleration filter is supposed to be second line of defense, but if the threshold doesn't calibrate to the grind regime, it's just noise filtering

---

## 3. **VWAP distance >= 2.0% may be too permissive for non-accelerating trend confirmation**

**The problem:**
- 2.0% is a very small margin above VWAP — easily satisfied by intraday noise
- HYP-024 tested >= 10% and >= 15% thresholds; 2.0% was never validated anywhere in our research
- If a stock is only 2% above its VWAP, it's barely out of the consolidation zone — not confirmation of an established uptrend

**Why it matters:**
- We're trying to differentiate grind (established trend) from impulse (spike-chase), but 2.0% VWAP distance doesn't actually prove "established trend"
- This threshold came from the grinder profile archetype (MDBX entry $0.74 vs VWAP $0.70 = 5.7%) but the rule hardcoded 2.0% as a floor, not a typical value

---

## Recommendation

**Biggest single risk: #1 (VWAP corruption on sub-$1 stocks)** — because:
- It's structural (VWAP data quality degrades at low prices)
- It's unvalidatable in backtests (we test with the corrupted data)
- If real in live trading, it breaks the entire 3-way entry gate

**Next step before Phase 1 backtest:**
- Engineer should compute VWAP noise distribution on Feb 24–Mar 3 for sub-$1 vs >$1 tickers
- Report: median intra-bar VWAP change, max single-bar change, bid-ask spread as % of VWAP
- If sub-$1 noise is > 1.5% of VWAP (which I suspect it is), recommend either:
  - Split the rule: use VWAP distance >= 2.0% only for >$1 tickers, skip VWAP filter for sub-$1
  - OR: modify entry gate to require VWAP confirmation + volume ratio >= 2.0 (dual validation instead of single VWAP gate)
