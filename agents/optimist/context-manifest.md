# Optimist Context Manifest

## What Manager should provide at session start
- The research question being investigated
- Current findings summary (what worked, what didn't)
- Relevant data extracts (not full datasets — curated snippets)
- Any code or formula being questioned
- What has already been tried

## What Optimist does not need
- File paths or access credentials
- Full parquet datasets
- Bash or Python execution capability
