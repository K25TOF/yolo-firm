## Methodological notes

- Trading PnL distributions are typically right-skewed with fat tails — parametric assumptions (normality) rarely hold. Default to bootstrap CIs.
- When evaluating parameter sweeps, always count the number of combinations tested. At p<0.05, expect 1 false positive per 20 tests. Apply Benjamini-Hochberg correction as default (less conservative than Bonferroni, better suited to exploratory research).
- For proportion CIs, use Wilson score interval as default (preferred over Wald, especially near extremes).
- V1 vs V2 population comparisons are universe-confounded unless ticker-dates are matched. Never interpret unmatched cohort differences as evidence of signal quality differences.
- Guard C result (prior session): 14/49 improved, 0/49 hurt. Binomial test p < 0.001 for improvement rate vs null, but n=49 is small — bootstrap CI recommended for the improvement proportion.
